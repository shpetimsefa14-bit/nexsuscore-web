Android: ADB, UID 2000 and Shizuku

What is ADB?

ADB stands for Android Debug Bridge. It is an official Google tool, part of the Android SDK Platform-Tools, that lets a computer send commands to an Android phone. Developers use it every day.

To use it you turn on Developer options, then USB debugging or Wireless debugging. The first time, the phone asks you to authorize the computer. On Android 11 and newer, Wireless debugging can pair over Wi-Fi with a code, so no cable is needed.

What is UID 2000?

Android gives every app and system process a number called a UID. Android uses it to decide what that process is allowed to do. Each normal app gets its own UID, and root is UID 0.

Commands you send through ADB run as the shell user, which is UID 2000. It sits in the middle:

  • It can use system tools such as pm, am, settings, wm and dumpsys.
  • It can stop apps, change some system settings and grant certain permissions.
  • It cannot read other apps’ private data, rewrite system files or do everything root can.
What is Shizuku?

Shizuku is a free app that starts a small helper process with shell (UID 2000) permission and lets other apps use it. Each app has to ask, and you approve or deny it in a prompt.

You start Shizuku once, either with Wireless debugging on the phone itself (Android 11+) or with ADB from a computer. After that, apps like Nexus Core can work without a cable and without root. If you started it with Wireless debugging, start it again after you restart the phone. You can revoke any app in Shizuku at any time.

What does Nexus Core do with this access?

It uses shell access for the tools you see in the app:

  • Game Mode and App Optimizer: give your game priority and stop busy background apps, then restore everything afterwards.
  • In-Game Speed Bar: a live FPS and ping overlay.
  • Ping tools: latency checks, DNS switching and blocking background traffic.
  • VIP options: RAM cache sweep and ZRAM compression.
  • ADB Shell terminal: run commands inside the app, for example to change DPI.
Is shell access safe?

It is limited by design. Shell access cannot unlock your bootloader, replace system files or read other apps’ private data. You can take it away at any time by turning off Wireless debugging or stopping Shizuku.

One rule matters: only approve apps you trust. Any app you approve in Shizuku can run shell-level commands.

Nexus Core for Windows

What is the Windows version?

It is a desktop optimizer for Windows PCs, made for gamers and for anyone who wants more performance, a cleaner system and more control. It runs as a normal Windows program.

Its dashboard shows live CPU, RAM and GPU usage, and a One-Click Boost button lets you start an optimization without opening each tool yourself.

What are the optimization profiles?

Each profile is a focused tool for one job:

  • Safe Optimizer: a careful clean-up meant for everyday use.
  • Process Optimizer: manages the programs running in the background that use your processor and memory.
  • GPU Optimizer: graphics-related settings for smoother games.
  • RAM Purge: frees up memory that is being held but not needed.
  • Bloatware Remover: removes apps you do not need and that run in the background.
What are SFC, DISM and SMART?

These are built-in Windows checks that Nexus Core makes easier to run:

  • SFC (System File Checker) scans protected Windows files and repairs the ones that are damaged.
  • DISM repairs the Windows image that SFC takes its good copies from.
  • SMART is the health report your drive keeps about itself. It can warn you before a disk starts failing.

SFC and DISM need administrator rights, so Windows will ask for permission when you run them.

What are registry tweaks and AI Diagnostics?

The Windows registry is the database where Windows and your programs store settings. A registry tweak changes one of those settings, for example to change how Windows behaves while you play.

The AI assistant helps you diagnose system errors, suggests tweaks and can run custom scripts. Registry changes affect the whole system, so read each change before you apply it.

What do Emulator & ADB, Network and Storage do?
  • Emulator & ADB: tunes the Android emulators you use to play mobile games on PC, and connects to Android phones over ADB. It is the same ADB described above.
  • Network: shows what your PC is sending and receiving.
  • Storage: finds duplicate files and junk files so you can clear them.
What should I do before making system changes?
  • Create a Windows restore point so you can go back.
  • Change one thing at a time, so you know what helped.
  • Do not delete system files or apps you do not recognize.
  • Back up important files before using the cleaner.

Modified operating systems

What is a modified operating system?

It is an official operating system that someone has changed. On Android these are usually called custom ROMs. Instead of an app working on top of the system, the system itself is different.

Because the changes live inside the system, they apply to every app and stay after a restart. Apps with shell access, like Nexus Core, cannot reach that deep.

What can a modified system change?

A phone system is built in layers: bootloader, kernel, the Android system (framework and system apps), then your apps. A modified system can change any of them:

  • Kernel: how the processor, memory and tasks are managed.
  • System: services, system apps and default settings. Unwanted apps can be removed and features added.
  • Startup scripts and properties: settings applied every time the phone boots.
  • Root access: some systems include it from the start.

Which of these Nexus OS changes is described in the Nexus OS section.

How is one installed?

Usually you unlock the phone’s bootloader, then flash the system image with fastboot or a custom recovery. The exact steps depend on your phone model, so follow the instructions for your device.

What should I do before installing one?
  • Back up your data. Unlocking the bootloader usually erases the phone.
  • Check that your exact phone model is supported.
  • Keep the official firmware so you can go back.
  • Know that it can void your warranty and can stop some banking or payment apps from working.
  • Only flash images from sources you trust.

Make a bootable USB with Rufus

Rufus is a free Windows tool that writes an image (ISO) file to a USB drive, so your PC can start from it. It is made by Pete Batard, not by Nexus Core.

  1. Prepare the drive

    Plug in a USB drive and back up anything you need from it. Rufus erases everything on the drive. Have your .iso file ready on your PC.

  2. Open Rufus

    Install Rufus with the button below and open it. It runs without installing, and Windows will ask for permission to start it.

  3. Choose the drive

    Under Device, pick your USB drive. Check the name and size carefully so you do not erase the wrong drive.

  4. Choose the image

    Under Boot selection, click Select and pick your .iso file. Rufus fills in the partition scheme and file system for you. Leave them as they are unless you know you need a change.

  5. Click Start

    Rufus warns that all data on the drive will be destroyed. Confirm, wait until the bar shows Ready, then close Rufus.

  6. Boot from the USB

    Restart the PC and open its boot menu during startup. The key depends on the maker, often F12, F10, Esc or Del. Choose your USB drive from the list.

Only use image files from sources you trust, and double-check the drive in the Device list before you click Start.

Privacy policy

What we collect

We do not collect or store the optimization settings, system information or ADB/Shizuku commands run by the Windows or Android app — those actions take place locally on your device and are never transmitted to our servers.

If you purchase a VIP subscription or feature, payment is processed by our payment provider using your bank card details. We do not receive, see or store your full card number — only a payment confirmation and subscription status are passed back to us by the payment provider.

This website does not use cookies, analytics or tracking scripts beyond what is strictly necessary to serve the page.

How we use it

  • Google account info — to create your account, let you sign in across devices, and provide support if you contact us.
  • Payment confirmation — to activate and manage your VIP subscription, and to handle refund or billing requests.
  • We do not use your data for advertising, and we do not sell your data to third parties.

Permissions and Shizuku/ADB

On Android, Nexus Core uses Shizuku to run commands with shell-level (ADB) access — the same access level you would get by connecting your phone to a computer with Android Debug Bridge. This lets the app manage background apps and change certain system settings, but it cannot read other apps' private data, modify system files, or access anything without root. You grant this access yourself inside Shizuku, and you can revoke it at any time by opening Shizuku and removing Nexus Core's permission, or by stopping the Shizuku service.

On Windows, some tools (SFC, DISM, registry tweaks) request administrator rights from Windows itself to make system-level changes you choose to apply. These changes happen locally on your PC; nothing is sent to us.

Nexus OS

Nexus OS is a different product from the Nexus Core app: it is a modified operating system, changed at the root/system level rather than an app running on top of your existing system. Because it replaces part of the operating system itself, it can reach deeper than Shizuku/ADB access — for example, system services, default apps and startup behavior. Installing it is a separate, deliberate step (typically unlocking the bootloader and flashing the image) and does not happen through the Nexus Core app.

This does not change what Nexus Core itself collects — Nexus Core's own data handling, described above, stays local and limited to your account regardless of which operating system you run it on. If you choose to install Nexus OS, we recommend backing up your data first, as doing so can erase your device and may affect banking or payment apps that check for a modified system.

Sharing and storage

Your account information (from Google Sign-In) and subscription status are stored securely and are not shared with third parties, except the payment provider that processes your purchase, and Google, which provides the sign-in service itself. We do not share your data with advertisers or data brokers.

Children and age requirements

Nexus Core is intended for users aged 16 and older. If you are under 18, you may only make a purchase (such as a VIP subscription) with the consent and involvement of a parent or legal guardian, who should supervise any use of a bank card. We do not knowingly collect personal data from children under 16.

Questions, answered

Quick answers about setup, safety, privacy and support. Tap a question to open it.

What is Nexus Core?

Nexus Core is a performance suite for gamers. The Windows app cleans and tunes your PC. The Android app prepares your phone for gaming by giving your game priority and pausing busy background apps.

Both apps work on the system you already have. They change settings and background processes, not your game files.

What does Nexus Core change on my device?

On Android, it changes system settings and stops background apps for the length of your session. On Windows, it works with processes, system settings and the registry tweaks you choose to apply.

It never touches your game files, and you decide what to apply.

Do I need root on Android?

No. Nexus Core uses Shizuku, which gives it shell-level (ADB) access without rooting your phone. That is enough for Game Mode, the Speed Bar, ping tools and the ADB shell.

Root is a deeper level of access that Nexus Core does not need.

Is Shizuku required, and is it safe?

On Android, yes. Shizuku is what gives Nexus Core permission to manage apps and settings.

You approve Nexus Core yourself in a prompt, and you can remove that permission at any time in Shizuku or by turning off Wireless debugging. Only approve apps you trust, because any app you approve can run shell-level commands.

How do I set up Android?
  • Install Shizuku and start its service.
  • Approve Nexus Core in Shizuku, using Wireless debugging or a USB connection.
  • Open Nexus Core, pick your game and tap Optimize.

It needs Android 11 or newer. If you started Shizuku with Wireless debugging, start it again after you restart your phone.

How do I set up Windows?

Download the installer (.exe), run it and open the dashboard. You will see live CPU, RAM and GPU usage. Then pick a profile or press One-Click Boost.

Some tools, such as SFC, DISM and registry tweaks, need administrator rights, so Windows will ask for your permission when you run them.

Can I undo an optimization?

Yes. On Android, Game Mode restores your settings when the session ends. On Windows, tweaks can be switched back.

Before bigger changes on Windows, it is a good idea to create a restore point and change one thing at a time.

What is the difference between Nexus Core and Nexus OS?

Nexus Core is an app that tunes the system you already have. Nexus OS is a separate product: a modified operating system, changed down to the root.

Installing Nexus OS is a deliberate step that usually means unlocking the bootloader, and it can erase your phone. Read the Nexus OS section and back up your data first.

Can I try it for free?

Yes. Both the Windows and the Android app are free to try. Some extra options, such as the RAM cache sweep and ZRAM compression on Android, are VIP features.

What data do you collect?

If you sign in with Google, we receive your name, email address and profile picture to create your account. Your optimization settings, system information and ADB commands stay on your device and are never sent to us.

We do not sell your data or use it for advertising. See the Privacy policy section for the full details.

Who can use Nexus Core?

Nexus Core is meant for people aged 16 and older. If you are under 18, a parent or guardian needs to be involved in any purchase.
